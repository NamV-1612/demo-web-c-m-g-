# Đồ án Web - Nhóm 5 (RIPT1307-KTHP)

## 💻 Công nghệ sử dụng

**Frontend:**

- **Framework/Thư viện:** React 17, UmiJS, Ant Design v4
- **Ngôn ngữ:** TypeScript

**Backend:**

- **Framework:** Node.js, Express
- **Cơ sở dữ liệu:** MongoDB (Mongoose)
- **Bảo mật:** JWT Authentication, bcryptjs
- **Lưu trữ ảnh:** Cloudinary
- **Ngôn ngữ:** TypeScript

**Deployment:**

- Cấu hình Docker, deploy lên Render.

## 🚀 Hướng dẫn chạy dự án (Local)

**1. Cài đặt thư viện:**

```bash
# Tại thư mục gốc (Frontend)
npm install

# Chuyển vào thư mục backend và cài đặt thư viện cho BE
cd backend
npm install
```

**2. Khởi chạy:**

```bash
# Bật Terminal 1 - Chạy Backend:
cd backend
npm run dev

# Bật Terminal 2 - Chạy Frontend:
npm run dev
```
